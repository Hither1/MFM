# MFM
Multimodal Filesystem Memory

## Branch `spatial-grid`

The MCU submodule (`MCU/`, branch `spatial-grid`) carries the mfm arm of the dragon
benchmark: the world-model chassis with the Multimodal Filesystem Memory beside its log,
the carry of earlier lives, and the experiment options of September 2026 (thin contract,
atoms, own scripts and reflexes, the meta-level skill package, visual-only, human-play).
What each option means and how an arm is launched, read out and tested:
[`MCU/README-mfm-arms.md`](MCU/README-mfm-arms.md). The experiment record (plans,
progress, findings, read-out scripts) is under `tasks/mfm-three-layer.*/`; the unit tests
in `tests/` run against the MCU checkout named by `MFM_MCU_ROOT`.
