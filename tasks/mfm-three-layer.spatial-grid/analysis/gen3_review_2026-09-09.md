## 2. Autonomy and the size of the harness

  the venv python), reflexes (`mine/reflexes/*.py`, every 4 ticks, at most 4, 3 s, `_` prefix off),
  skills (`mine/skills/<name>/SKILL.md` -> catalog next turn, carried), any file under `mine/` (kept and

  numpy (of3r ran `python tools/episodes.py --previous --steps 184 257 --q ...` and PIL crops in heredocs).
- Per-turn cost: AGENTS.md 12.9 KB (plan-gen3 3e wanted <= 8 KB; the compact index saved ~1 KB) + the turn
  message (checklist, [STATE]/vitals/inventory/hotbar/held/GUI/cursor/grid, [RECENT] 6, [MAP], [OWN],
  [EXPECTED]/[OBSERVED], [WORKING] <= 1,500 chars, [DIGEST] <= 2,000 chars, [RECALL]).
- Bugs/frictions found:
  a. `memory.KEEP_BETWEEN_TURNS` has no `.agents`: `sweep_foreign` (end of every turn) rmtree's the skill
     catalog; `sync_skill_catalog` at the start of the act turn (agent.py 4068) rebuilds it, so it works,
     but the invariant is accidental. One line: add ".agents" to the keep set.
  b. `previous.NOT_CARRIED` has no `skills`: the previous life's harness skills (gen-2 texts) are linked under
     `previous/life_<i>/skills/` (of3r: previous/life_1/skills exists) -- stale doctrine reachable by grep,

  c. DIGEST_CAP 2,000 chars: of3r's digest.md is 2,142 B, so the seed's own digest is cut at ~93% with a
     pointer. 3,000 would show the seeds whole (of1r 1,773, of2r 1,141).
  d. Root-level outputs (death.png, then_now.png, zoom.png) are swept at the end of the turn by design; the
     memory skill says to save what matters under mine/. Fine, worth knowing when reading rollouts.
